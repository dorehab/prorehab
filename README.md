# DoRehab Pro ID — Website Panduan Rehabilitasi Cedera Olahraga

## Struktur Folder
```text
dorehab-pro-id/
├── index.html       # Halaman utama aplikasi web (UI, navigasi, modal FITT & Prinsip Terapi)
├── css/
│   └── styles.css   # Styling tambahan, animasi kartu latihan, dan custom scrollbar
├── js/
│   ├── data.js      # Database lengkap 11 cedera olahraga, prinsip klinis, dosis FITT, foto & query YouTube
│   └── app.js       # Logika render dinamis, pencarian, filter area tubuh, dan kontrol fase
└── README.md        # Dokumentasi struktur proyek dan cara menjalankan
```

## Cara Menjalankan
1. Ekstrak file ZIP ini ke folder komputer Anda.
2. Klik dua kali file `index.html` untuk membukanya langsung di browser (Chrome, Edge, Safari, atau Firefox).
3. Pastikan perangkat terhubung ke internet agar font Google Fonts, Tailwind CSS, foto latihan, dan tautan video YouTube dapat dimuat dengan sempurna.
